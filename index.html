Corps humain

Vérification du casque…

  • Pince pouce et index d'une main pour attraper le corps, le déplacer et le retourner.
  • Pince des deux mains et écarte-les pour agrandir ; rapproche-les pour réduire ; tourne-les pour faire pivoter.
  • Continue d'agrandir : tu entres dans l'organe, puis dans ses cellules, jusqu'aux atomes.
  • Approche ton index d'une chose pour lire ce que c'est sur le panneau.
